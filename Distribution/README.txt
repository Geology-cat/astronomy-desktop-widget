天文情報ウィジェット 1.1.0
==============================

macOSのデスクトップに常駐し、太陽・月・天文薄明の時刻を表示するアプリです。

【インストール】

1. 「天文情報ウィジェット.app」を、同じ画面にある「アプリケーション」フォルダへドラッグします。
2. アプリケーションフォルダを開き、「天文情報ウィジェット.app」を起動します。
3. 位置情報の使用を許可すると現在地を使用します。許可しない場合は設定した地点を使用します。

【「開発元を確認できない」などの警告が表示された場合】

まず、アプリケーションフォルダ内の「天文情報ウィジェット.app」を
controlキーを押しながらクリックし、「開く」を選択してください。

それでも起動できない場合のみ、次の手順を実行してください。

1. このDMG内の「Gatekeeper解除.scpt」をダブルクリックします。
2. Script Editorが開いたら、ツールバーの「実行」ボタン（▶）を押します。
3. 表示された対象パスが「天文情報ウィジェット.app」であることを確認します。
4. 「解除して起動」を押し、macOSの管理者認証を行います。

このAppleScriptが変更するのは、Bundle ID
「jp.yamashitaujou.AstronomyDesktopWidget」と一致するアプリの
com.apple.quarantine隔離属性だけです。Mac全体のGatekeeper設定は変更しません。
配布元を信頼できる場合に限り使用してください。

【基本操作】

・ウィジェットの空いている部分をドラッグして移動できます。
・右上の歯車、またはメニューバーの月アイコンから設定を開けます。
・設定では現在地／指定地点、文字サイズ、ログイン時の自動起動を変更できます。
・通常のアプリウインドウを開くと、その背後へ退避します。

【動作環境】

macOS 13 Ventura以降
Intel Mac／Apple Silicon Mac対応

天文時刻は一般利用向けの近似計算です。航法・測量など高精度を要する用途には使用しないでください。
