# 天文情報ウィジェット

macOSの壁紙上に常駐し、現在地または指定地点の太陽・月・天文薄明を表示するネイティブアプリです。インターネット接続なしで計算できます。

[最新版のDMGをダウンロード](https://github.com/Geology-cat/astronomy-desktop-widget/releases/latest)

## 表示内容

- 太陽：日の出、南中時刻と高度、日の入
- 月：月齢、月の概形、月の出、南中時刻と高度、月の入
  - 南中と月の入は、既定では「その日にのぼった月」について表示します。翌日にまたぐ場合は「翌4:56」のように表示します。
  - 設定で「その日のうちの時刻」に切り替えると、その日のうちに起きる南中と月の入を表示します。前日にのぼった月のものには「（前日）」が付きます。
- 今日と明日：朝・夕の天文薄明（太陽中心高度 −18°）

時刻はMacで選択中のタイムゾーンで表示します。高緯度などで該当イベントがない場合は `—` になります。

## 使い方

1. `dist/天文情報ウィジェット.app` を「アプリケーション」フォルダへ移動して開きます。
2. 初回の位置情報ダイアログで許可すると現在地を使用します。
3. 歯車ボタン、またはメニューバーの月アイコンから設定を開けます。
4. パネルの空いている場所をドラッグすると配置を変更できます。
5. 設定画面で手動の観測地点、文字サイズ、月の南中・月の入の基準、ログイン時の自動起動を指定できます。

## 開発・検証

```sh
swift test
./scripts/build_app.sh
```

対応OSはmacOS 13以降です。天文時刻は一般利用向けの近似計算であり、航法・測量など高精度を要する用途には使用しないでください。

## 配布用DMG

```sh
./scripts/build_dmg.sh
```

`dist/天文情報ウィジェット-1.2.0.dmg` が生成されます。DMGにはUniversal版アプリ、`README.txt`、`Gatekeeper解除.scpt`、アプリケーションフォルダへのリンクが含まれます。

Gatekeeper解除AppleScriptは、Bundle IDが一致する「天文情報ウィジェット.app」の隔離属性だけを解除します。Mac全体のGatekeeper設定は変更しません。

## ソースコードの管理

- `main` ブランチへのpushとPull Requestで、GitHub ActionsがSwiftテストを実行します。
- `.build/` と `dist/` はGit管理対象外です。配布DMGとSHA-256はGitHub Releasesで公開します。
- 現時点では利用ライセンスを指定していません。
