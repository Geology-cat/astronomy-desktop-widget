# 天文情報ウィジェット

macOSの壁紙上に常駐し、現在地または指定地点の太陽・月・天文薄明を表示するネイティブアプリです。インターネット接続なしで計算できます。

[最新版のDMGをダウンロード](https://github.com/Geology-cat/astronomy-desktop-widget/releases/latest)

## 表示内容

- 太陽：日の出、南中時刻と高度、日の入
- 月：月齢、月の概形、月の出、南中時刻と高度、月の入
  - 南中と月の入は、既定では「その日にのぼった月」について表示します。翌日にまたぐ場合は「翌4:56」のように表示します。
  - 設定で「その日のうちの時刻」に切り替えると、その日のうちに起きる南中と月の入を表示します。前日にのぼった月のものには「（前日）」が付きます。
- 表示日とその翌日：朝・夕の天文薄明（太陽中心高度 −18°）
- 暗夜：表示日の夕方から翌日の朝にかけて、太陽の影響（天文薄明）も月の影響もない時間帯
  - 「夕の天文薄明終了〜朝の天文薄明開始」から「月の出〜月の入」（月が地平線上にある時間）を除いて求めます。
  - 区間ごとに、開始・終了が薄明と月のどちらで決まったか（薄明終了／月の入、月の出／薄明開始）と合計時間を表示します。
  - 夜全体のうち暗夜と月明かりの部分をタイムラインで示し、白い線で現在時刻を示します。
  - 満月前後で一晩中月が出ている夜や、高緯度で天文薄明が終わらない夜は「暗夜なし」と表示します。

- 日付の切り替え：日付の左右の「‹」「›」で前後の日へ、日付をクリックするとカレンダーから選べます。今日以外の日は日付が黄色になり、「今日」で戻れます。今日以外の日の月齢は、その日の正午の値です。

時刻はMacで選択中のタイムゾーンで表示します。高緯度などで該当イベントがない場合は `—` になります。

## 使い方

1. `dist/天文情報ウィジェット.app` を「アプリケーション」フォルダへ移動して開きます。
2. 初回の位置情報ダイアログで許可すると現在地を使用します。
3. 歯車ボタン、またはメニューバーの月アイコンから設定を開けます。
4. パネルの空いている場所をドラッグすると配置を変更できます。
5. 設定画面で観測地点、文字サイズ、月の南中・月の入の基準、ログイン時の自動起動を指定できます。
   - 観測地点は「現在地を使用」のほか、都道府県庁所在地のリスト（北海道は札幌・函館・旭川・室蘭・帯広・釧路・北見・網走・稚内・根室）から選ぶか、緯度・経度を入力できます。
   - 「現在地を使用」のときは、取得した現在地の緯度・経度を設定画面に表示します。

## 開発・検証

```sh
swift test
./scripts/build_app.sh
```

対応OSはmacOS 13以降です。macOS 10.12〜12向けには、同じ機能をAppKitで実装したLegacy版があります（下記）。天文時刻は一般利用向けの近似計算であり、航法・測量など高精度を要する用途には使用しないでください。

## 配布用DMG

```sh
./scripts/build_dmg.sh
```

`dist/天文情報ウィジェット-1.4.0.dmg`（macOS 13以降用）と `dist/天文情報ウィジェット-Legacy-1.4.0.dmg`（macOS 10.12〜12用）が生成されます。各DMGにはアプリ、`README.txt`、`Gatekeeper解除.scpt`、アプリケーションフォルダへのリンクが含まれます。

Gatekeeper解除AppleScriptは、Bundle IDが一致する「天文情報ウィジェット.app」または「天文情報ウィジェット Legacy.app」の隔離属性だけを解除します。Mac全体のGatekeeper設定は変更しません。

## macOS 10.12〜12用（Legacy版）

```sh
./scripts/build_legacy_app.sh
```

`dist/天文情報ウィジェット Legacy.app` が生成されます（Intel、macOS 10.12以降）。

- SwiftUIはmacOS 10.15以降のため、画面は `Legacy/Sources/` でAppKitを使って作り直しています。計算部分（`Sources/AstronomyCore`）と表示用の文字列処理は通常版と共通です。
- SwiftPMでは対象OSをターゲットごとに分けられないため、`swiftc` を直接呼んでビルドします。
- macOS 10.14.3以前にはSwiftランタイムが含まれないため、Xcode付属の後方互換ランタイム（`swift-5.0/macosx`）をアプリ内の `Contents/Frameworks` へ同梱します。新しいmacOSではOS側のランタイムが優先されます。
- ログイン時の自動起動は `~/Library/LaunchAgents` に起動用plistを置く方式です。
- Bundle IDは `jp.yamashitaujou.AstronomyDesktopWidget.Legacy` です。

## ソースコードの管理

- `main` ブランチへのpushとPull Requestで、GitHub ActionsがSwiftテストを実行します。
- `.build/` と `dist/` はGit管理対象外です。配布DMGとSHA-256はGitHub Releasesで公開します。
- 現時点では利用ライセンスを指定していません。
